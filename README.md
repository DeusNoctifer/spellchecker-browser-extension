# SpellChecker Browser Extension

![JavaScript](https://img.shields.io/badge/javascript-%23F7DF1E.svg?style=for-the-badge&logo=javascript&logoColor=black)

**SpellChecker Browser Extension** is a lightweight browser extension that helps users improve their English writing by automatically detecting and correcting grammar mistakes while typing.

The extension provides fast grammar suggestions directly inside text inputs, making writing smoother and more accurate across websites.

---

## 🚀 Key Technologies

* **Frontend:** Vanilla JavaScript for lightweight execution and browser compatibility.
* **Grammar Engine:** External grammar correction API integration for real-time suggestions.
* **Architecture:** Browser Extension APIs for content injection and text interaction.

---

## 🏗️ Extension Features

### Core Modules

1. **Text Detection:** Monitors user input fields dynamically across supported websites.
2. **Grammar Analysis:** Sends written content to a grammar correction API.
3. **Suggestion Engine:** Displays corrected grammar suggestions in real time.
4. **Lightweight Injection:** Runs efficiently without affecting page performance.
5. **Browser Integration:** Uses extension APIs to interact directly with web pages.

---

## 🛠️ Local Installation

To run the extension locally:

### **1. Clone the repository**

```bash
git clone https://github.com/DeusNoctifer/spellchecker-browser-extension.git
```

### **2. Open the project folder**

```bash
cd spellchecker-browser-extension
```

### **3. Load the extension in your browser**

1. Open your browser extensions page.
2. Enable **Developer Mode**.
3. Click **Load unpacked**.
4. Select the project folder.

---

## ⚡ Usage

1. Open any supported website with text inputs.
2. Start typing in English.
3. The extension will automatically analyze the text and suggest grammar corrections.
